# Utility pages: archives, duplicates and users

These pages sit outside the normal service-day flow and are available from the **Menu** dropdown.

## 1. Archives

**Menu → Archives** lists archived songs, set lists and Tarp presentations.

- Archived items are hidden from normal pickers, planning lists and the live-session selector.
- Existing set-list snapshots keep working: a song or Tarp presentation archived after a set list
  was built remains available to that saved set list.
- Select one or more rows and use **Restore selected** to make them selectable again.
- **Delete selected** permanently removes the archived rows and any owned assets or page data.
  This cannot be undone.
- The page is shown only to users with permission for songs, set lists or Tarp.

## 2. Duplicate songs (DeDupe)

**Menu → DeDupe** groups songs that look like the same title or alternative title.

- Groups show the candidate songs with author, CCLI, key and first lyric lines.
- **Compare** opens a line-level lyric diff before choosing a version.
- **Prefer** keeps the selected song as the reference for future imports and matching.
- Removing a duplicate archives or deletes that copy; existing set-list items are not silently
  retargeted. Review affected set lists before deleting a heavily used version.
- Re-run **Find duplicates** after bulk imports or SongSelect downloads.

## 3. Users and permissions

**Menu → Users** is visible to administrators.

- Roles provide a starting point:
  - **Admin** — all modules, user management and settings.
  - **Editor** — all content modules except settings and user management.
  - **Operator** — live control, set lists and images.
- Per-module permissions can override the role defaults for Songs, Set lists, Images, Tarp, Bible,
  Live, ChurchSuite, Backgrounds, Stingers and Settings.
- Administrators can create users, reset passwords, rename users and edit roles/permissions.
- Users can register passkeys and manage their own password from the account panel.
- Personal settings stay per user, including SongSelect credentials, clicker mappings and saved
  external presentations.
- The activity log records sign-ins and live commands for troubleshooting. Its retention period is
  configurable.
